# Sydney network diagram: topology rebuild (layout v2)

## Design reference

The visual reference is the official [Transport for NSW Sydney rail network map](https://transportnsw.info/sydney-trains-network-map) (2024 edition). **This application's schematic is an independently drawn, interactive interpretation.** It does not reproduce the artwork, is not a geographically accurate map and cannot be used as authoritative advice about current service patterns or platform arrangements.

## Why this is a new layout, not another styling patch

The previous schematic placed the entire Western route nearly horizontally, North Shore lines above the city and the southern routes below a very small City Circle. It was displayed inside a landscape-height SVG frame, making lines and labels almost invisible at common browser widths. Styling and line-code badges could not fix the underlying geometry.

Version 2 explicitly rebuilds the fixed anchor locations for the following districts:

| District | Diagram organisation |
| --- | --- |
| Richmond and Western | Western branches on the left, meeting Blacktown and flowing east via Parramatta, Lidcombe and Strathfield |
| North Shore | Hornsby and Berowra north, Chatswood and the Harbour further south-east |
| Northern | Epping links to Hornsby and Strathfield independently of the North Shore route |
| M1 Metro | Tallawong from the left to Epping, Chatswood and via the new CBD Metro stations to Sydenham |
| City Circle | Enlarged eastern loop around Wynyard, Town Hall, Circular Quay, St James, Museum and Central |
| Eastern Suburbs | T4 extends to Bondi Junction on the eastern edge |
| South-West | Regents Park, Bankstown, Liverpool, Glenfield, Leppington and Macarthur below the Western spine |
| Airport / Illawarra | Airport branch east of the main southern route; Illawarra descends via Hurstville/Sutherland, branching to Cronulla and Waterfall |

All corridor connections remain encoded as station-to-station routes. New 0° / 45° / 90° bend generation produces continuous octilinear edges between hand-placed anchors, and trains continue to use the GTFS-derived station positions for matching to the schematic.

**Geographic station positions are not changed** by this work. Switch to *Geographic map* for coordinates and OpenStreetMap context.

## Review previews before merging

The **Tests** workflow runs the application's regression suite and then executes `node scripts/preview-network.js`. Download the **sydney-network-diagram-layout** artifact from the pull request's latest Tests run. It contains:

- `network-schematic-sydney-v2.svg`: full suburban diagram
- `network-schematic-city-v2.svg`: enlarged CBD / North Shore / inner-suburban focus

These SVGs show the actual positions and line paths generated by `buildSchematic()`, not a manually drawn mock-up. Labels are approximately collision-filtered for convenient preview. The deployed app has additional real-time train icons, station selection, incident overlays, zoom and its own browser-side collision handling, none of which are represented in the static previews.

**Acceptance must involve reviewing these images before merge.** Inspect the alignment of the line groups against the TfNSW reference, City Circle proportions, labelled termini and interchange hierarchy. Because this is a visual project, passing automated tests alone is not acceptance.

## Constraints and future data checks

- The reference map documents its publication time. Current service patterns may differ, particularly where conversions or extensions have occurred. Do not infer current operating routes from this schematic.
- Live vehicle marker positions are estimated on the schematic by matching GTFS vehicle coordinates to known station intervals. Missing matches are not fabricated.
- Station geolocation, alerts, train position collection, crowding, patronage and Home Screen update files remain separate, accepted workflows.
- The whole-state Intercity network remains accessible using **Whole network**; the suburban **Sydney** view intentionally prioritises the recognisable T1–T9 / M1 corridors rather than rendering distant intercity sections at equal visual scale.
